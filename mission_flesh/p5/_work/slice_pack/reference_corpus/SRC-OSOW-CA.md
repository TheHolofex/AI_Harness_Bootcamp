# California OSOW heavy-haul permits — classroom summary (course fixture)

Publisher: Course road cell (public FMCSA/state-practice flavored)
Document date: 2023-09-01
Source ID: SRC-OSOW-CA

## Points
Oversize/overweight moves on public highways require state permits, pilot cars where mandated, and time-of-day restrictions. Permits expire; a slipped sealift window can invalidate the road leg.
