Each module receives its own supplied case and machinery, so no module gate depends on another module's evidence. Final qualification still requires every program outcome to pass.

## Build under judgment

The authoritative core comprises README, course map, learning-objective ledger, authoring guide, and nine 30-line module skeletons. It defines:

- nine sessions of three facilitated hours;
- two hours of practice per session;
- three required workplace surfaces;
- one fixed workflow as the highest mandatory machinery;
- nine singly owned outcomes, PO-00–PO-08;
- 39 produced evidence products;
- 30 learner-visible `VERIFY:` supply edges;
- 3 evaluator-controlled `CUSTODY:` edges; and
- independent-module participation with program-level qualification closure.

## 2. Current shortfalls

### A. The course remains a skeleton

No detailed lessons, adapters, supplied cases, protected fixtures, scorer implementation, accessible same-state view, or recipient task bank exists. The structure can guide construction but cannot qualify a learner.

### B. Nine independent modules transfer integration burden into the supplied cases

Independence prevents a missed session from cascading. It also means each supplied case must make the module's first action authentic without relying on a learner-built artifact from the prior day. Coherence now depends on scenario design and cross-module terminology rather than a chained learner product.

### C. Module 00 is dense

One three-hour session now covers first use, delegation, capability limits, minimum responsibility screening, direction, protected acceptance, a communication artifact, and a controlled change. The first-value target remains plausible only as a design claim until timed with actual learners.

### D. Module 03 is dense

Every learner must complete both a contextual decision and a supplied safe tool operation within three hours, including composed hostile-content testing, approval, disconnect, and revocation. This is structurally coherent but unpiloted.

### E. Qualification logistics exceed the 27 facilitated hours

Independent-recipient sessions and reassessment/make-up attempts are explicitly outside facilitated seat-time. The 27-hour claim describes scheduled class sessions, not total organizational effort required to qualify a learner.

### F. Variation handling remains task-sensitive

Module 07 requires a pre-result repetition, deterministic-case, hard-gate, or exclusion rule. The skeleton intentionally provides no universal sample count. A weak adapter can still choose insufficient repeated controls unless the evaluation judge rejects the policy.

## 3. Red team

### Most likely first-week failure

A supplied Module 03 case contains licensed source text, a protected demographic attribute, instruction-like content, and a capability whose apparent read path can write a free-text external field. A weak adapter observes only named API calls and misses the free-text side effect. The skeleton requires the composed negative; implementation quality determines whether it is meaningful.

### Additional break attempts

1. **Module independence becomes nine disconnected labs.** Each session passes locally but learners do not perceive one transferable operating method.
2. **Module 00 time collapse.** Slow readers reach direction or controlled change after the three-hour boundary.
3. **Tool operation becomes button following.** The supplied capability makes least-authority and revocation obvious, allowing procedural imitation without judgment.
4. **No-tool reasoning becomes theater.** Learner records refusal while knowing the separate operation case is mandatory and unrelated to the decision.
5. **Stochastic false improvement.** A candidate passes on too few repeated controls.
6. **Hidden-case leakage at 200 learners.** Reused supplied cases reveal faults and expected outcomes.
7. **Recipient scarcity.** Independent recipients who have not taken the course cannot be scheduled outside class hours.
8. **Qualification delay.** Unseen reassessment cases and makeups create an unbudgeted tail after Friday morning.
9. **Accessibility substitution.** Narration is accepted as same-state operation despite lacking the causal control.
10. **Static-test overconfidence.** 413 passes are treated as educational validation rather than structural consistency.

## 4. Highest-leverage next moves

1. **Build and time Modules 00, 03, and 08 first.** They test the densest opening, the composed responsibility/tool boundary, and qualification/recipient logistics.
2. **Define one supplied-case contract and custody protocol.** It must make each module independently runnable while preserving shared vocabulary, authentic work, hidden-case rotation, accessible same-state operation, and protected evidence.
3. **Pilot the complete nine-session week with 20 learners.** Measure first-value time, actual practice, completion/HOLD rates, model/tool spend, scorer time, agreement, recipient capacity, and reassessment tail.

## 5. Better build

A superior implementation would add nine coherent supplied cases, a managed preflighted environment, one compact learner evidence interface, protected source/tool/fault/evaluation banks, accessible raw-state equivalents, automated receipts, calibrated judges, independent-recipient logistics, and telemetry. It would preserve module independence while using a common domain narrative and vocabulary so the course does not feel like disconnected certification stations.

The implementation effort and delivery budgets remain planning estimates until a pilot.

## Reference discrepancy

None. The frozen Reference permits no more than ten modules and 24–35 facilitated hours, so the current nine-module, 27-hour skeleton remains within its bounds. The Reference stays frozen.
