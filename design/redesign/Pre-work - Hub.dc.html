Everything runs on API keys Staff issue you three keys — OpenAI, xAI, and Anthropic. You will never sign into ChatGPT, Claude, or any monthly plan during this course. Several tools offer a subscription login and an API key option on the same screen; always take the API key path.
Twin-engine stack Required pair for class: the Codex app on your OpenAI key (home), plus OpenCode on your xAI key (second engine, Grok). Claude Code is optional and not required to pass pre-work.

Done means

  1. Required tools installed and configured against your three API keys
  2. Each major setup step's verify checks passed (fresh terminal after PATH changes)
  3. All four required agents created a file in Documents\HarnessBootcamp\prework-smoke\ that you can see in Explorer
  4. A setup log with at least one real failure and fix

There is no separate health-check pass. If something breaks later, re-run that section's verify — the rescue sheet prework/HEALTH_CHECK.md exists only for a full re-test.

Setup log

Keep a running log beside the checklist (copy prework/SETUP_LOG.md or any notes file). For each major step record result, errors, fix, and time. Monday asks for this trail.
