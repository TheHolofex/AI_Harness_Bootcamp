What you learn

Nine blocks, one arc — direct, verify, bound, transfer. Each is a skill you demonstrate with log evidence a peer could audit.

B0 · P1 — Direct Direct the harness

Stand up a working instrument from messy data, state acceptance criteria, and accept or reject with evidence — a rerunnable tool, not a one-shot chat.

P2 — Tune Encode your craft

Improve harness config with measured deltas, author machine-checkable tests, install durable memory, and package skills that fire unprompted.

P3 — Verify Command many minds

Run the same brief on two engines, use disagreement as a sensor, adjudicate with provenance — agreement ≠ truth, and you own the verdict.

P4 · P5 — Guard Work your knowledge, keep it clean

Scope AI into a linked vault, verify citations by walking the links, and detect poisoned intake — proving containment by absence of effect.

P6 · P7 — Bound Bound autonomy

Write an autonomy contract on real tool levers, prove stop and restart, and choose agent loop vs fixed pipeline with a human gate on exceptions.

P8 — Transfer Transfer the method

Author endpoint policy first, measure hold/degrade when the model changes, and leave with a 30-60-90 plan you run at your own desk.
