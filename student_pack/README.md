# Student pack (seed)

## Before Monday — pre-work (required)

You install your own workstation. **No golden image.**

1. Work through `../prework/README.md` and `INSTALL_GUIDE.md` on Windows 11.  
2. Fill `SETUP_LOG.md` as you go.  
3. Reach **GREEN** (or YELLOW with documented workaround) on `HEALTH_CHECK.md`.  
4. Bring laptop + setup log to Block 0. Monday verifies the gate, then First Light — it does not install the stack for you.

## In the Codex project (contact week)

1. Put `../operator/DIRECTION_BRIEF.md` and `../operator/OPERATOR_LOG.md` in your Codex project (root or `operator/`).
2. Create a Codex thread named **`Operator — Direction & Log`**.
3. **Before each mission:** open that thread, paste the starter from `DIRECTION_BRIEF.md`, co-write the five fields until status is LIVE.
4. **Run the mission** in a different thread against the live brief.
5. **After the mission:** back in the operator thread, paste the starter from `OPERATOR_LOG.md`, co-write the five log fields. You own the verdict.

The AI helps you produce the brief and log. It does not replace your judgment.

6. **After the log:** paste the closer from `PASS_BARS.md`. Self-check MVP with the AI — met / not yet + evidence pointers.

7. **Adversarial review (every block):** open a **new** Codex thread `Adversarial — [block]`. Paste the frozen prompt from `ADVERSARIAL_REVIEW.md` plus your artifacts, provisional verdict, and draft MVP checks. Take the attack. Copy `ADVERSARIAL: stood/wounded/failed — …` into the log. Fix bars if wounded.

8. **Measurement spine (every block):** after adversarial, update `MEASUREMENT_SPINE.md` — ritual 0–3 · mission HIT/PARTIAL/MISS · quality STRONG/ADEQUATE/WEAK · time to result (minutes). Paste the end-of-block prompt. ~3–5 minutes.

9. **Transfer thread (required every half-day):** create Codex thread **`Operator — Transfer 30-60-90`**. After **every morning and afternoon** block — once Direction/Log and pass-bar are done — paste the every-session prompt from `TRANSFER_30_60_90.md` and co-write with the AI. Session log row every time. Deep seeds on P2/P3/P5/P6/P7. **Seal only at P8.** Not a Friday worksheet.
