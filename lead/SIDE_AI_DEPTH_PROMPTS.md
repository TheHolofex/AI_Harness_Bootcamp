# Side-thread depth prompts (lead)
Use a separate AI thread students can see when a concept needs a diagram or deeper explanation.

## Harness loop
Draw act → observe → correct → accept with where humans bind the loop. One concrete example from today's mission.

## Judgment product vs answer
Contrast one-shot chat brief vs regenerable machine. Table: trigger, inputs, outputs, accept checks, owners.

## Walls (P2)
Diagram instructions / tests / memory / skills as four walls around the model. Show which wall today's delta moved.

## Agreement ≠ truth (P3)
Venn of engine A, engine B, world evidence. Show kill path when both agree and world disagrees.

## Containment (P5)
Pipeline: intake → quarantine → checks → trusted. Mark absence of effect as the success criterion.

## Autonomy contract (P6)
Two columns tool vs procedure; map stop authority.

## Agent vs pipeline (P7)
Decision tree: uncertainty high → agent or human; volume+schema stable → pipeline+gate.
