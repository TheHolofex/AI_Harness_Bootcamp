# Module 8 protected-case custody contract

Protected tasks live under `facilitator/cases/` (if present) and are not learner start-page links. The producer cannot edit the deciding check.

The protected checker `shared/case/verify_safeguards.py` is the deciding control for the adapter. Learners run it against their work copy. The checker must not be modified by the producer or placed inside the agent work surface that the learner's agent can reach.

- A README link to a protected case invalidates the case.
- A work tree that the checker cannot read because files were moved or renamed after the fact produces HOLD.
- A missing accessible equivalent holds the assessment.
