# Accessibility and equivalent inspection

Every decisive note is supplied as semantic text. No required fact depends only on a map, image, color, hover state, or scanned handwriting.

## Required access

- The public desk note and the package template must be keyboard reachable and screen-reader readable.
- Hours, window, and audience appear as text.
- Extra navigation time does not change the hard gates.

If an equivalent path does not expose the desk note or a package field, record `HOLD`. The facilitator may help open the material, but the learner must inspect it themselves.
