# Accessibility and equivalent inspection

Every brief is supplied as semantic text. No required fact depends only on a map, image, color, hover state, or scanned handwriting.

## Required access

- Pair files and gate output must be keyboard reachable and screen-reader readable.
- `PASS` and `HOLD` appear as text.
- Extra navigation time does not change the hard gates.

If an equivalent path does not expose a brief or a gate result, record `HOLD`. The facilitator may help open the material, but the learner must inspect it themselves.

## Requesting support

```text
Case ID:
Source or command step:
Interaction or access method:
State or relationship that is unavailable:

```

Do not include medical details, credentials, or unrelated personal information.
