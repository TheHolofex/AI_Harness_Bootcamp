# Module 4 · Diagnose and recover

Plan for one three-hour session. You will prove restore first using the explicit ledger, then localize the first missing field on a duty card for the Copper Span movement, seal that miss with a probe, make one authorized replace from the hashed baseline, and rerun in three distinct ways.

The ledger is desk-local. `permit_status` and `gate_time_mdt` are required fields on current rows. Those values are not a movement order.

## Start here

1. Open [the Module 4 lab](shared/MODULE_04_LAB.md).
2. Read the [public scoring rubric](assessment/PUBLIC_RUBRIC.md) before you change a file.
3. If you use assistive technology or need another way to inspect the ledger, read [Accessibility and equivalent inspection](shared/ACCESSIBILITY.md).

## What you inspect

The clean renderer writes a duty card with both `permit_status` and `gate_time_mdt` from the ledger. After restore is proved, a fault is placed that drops one field. You seal the first miss before you replace anything.
