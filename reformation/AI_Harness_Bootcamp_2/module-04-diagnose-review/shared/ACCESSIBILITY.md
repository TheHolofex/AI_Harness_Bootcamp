# Accessibility and equivalent inspection

Every decisive field is supplied as semantic text. No required fact depends only on a map, image, color, hover state, or scanned handwriting.

## Required access

- The ledger and `review.md` must be keyboard reachable and screen-reader readable.
- Field names `permit_status` and `gate_time_mdt` appear as text rather than color alone.
- Restore output is the exact phrase `RESTORE OK`.
- Learners may enlarge text, change contrast, use voice control, or redirect command output without changing the task.
- Extra navigation time does not change the hard gates.

## Equivalent source path

An equivalent view must preserve:

1. the complete ledger rows and header;
2. presence or absence of `permit_status` and `gate_time_mdt` as text;
3. the restore result; and
4. the sealed-first-miss record and probe output.

If an equivalent path does not expose a decisive field or restore result, record `HOLD`. The facilitator may help open the material, but the learner must be able to inspect it and make the judgment themselves.
