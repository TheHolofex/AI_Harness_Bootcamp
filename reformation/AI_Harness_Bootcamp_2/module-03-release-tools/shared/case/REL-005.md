# REL-005 · Gate hour for MH-6

Gate board for Mill Gate, 7 October 2026. Vehicle MH-6 has a true gate hour of 18:40 MDT. The board records when that vehicle may approach the gate. It does not order the vehicle to roll, and it does not release cargo.

The hour 18:40 MDT is locally true for MH-6. An outside desk that treats the hour as a movement order would commit burn-dressing cases that quality has not released. The hour remains a gate hour after you notice that it is true.

Do not copy this hour from a Zulu stamp. A vendor line that prints 18:40Z is a different clock. That collision is recorded in REL-023. This file states the local hour only.
