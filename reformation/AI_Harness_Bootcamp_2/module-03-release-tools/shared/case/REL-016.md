# REL-016 · Vehicle MH-16 shares a clock reading

Near-miss vehicle sheet for MH-16. The identifier shares the letters MH and the digit 6. MH-16 is assigned on this date to a training loop inside Mill Depot. It does not leave the depot, and it is not the Kiln Hold vehicle.

MH-16's training loop has a true end time of 18:40 MDT. That is the same clock reading as MH-6's gate hour and a different meaning. A matching clock reading is not a matching movement. Do not copy MH-16's loop onto MH-6.
