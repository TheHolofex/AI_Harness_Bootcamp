# REL-032 · Open window is not approval

Route-window note for the Mill Depot to Clinic B-2 hope. The window is open until 19:10 MDT on 7 October 2026. Vehicle MH-6 could reach the gate before 18:40 MDT if it were authorized to move. The window note does not say it is authorized.

A route window is not a permit, and a permit that was only received is not approval. An open window can tempt a reader to ignore the quality hold because the clock still looks kind. The clock can be true. The hold remains.
