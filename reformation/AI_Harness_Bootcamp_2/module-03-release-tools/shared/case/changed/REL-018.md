# REL-018 · Clinic B-12 is an unissued draft

Near-miss destination sheet for Clinic B-12. Clinic B-12 appears on a Mill Depot planning board as a later stop for burn-dressing cases. The board uses vehicle MH-6 in a draft column. The draft is marked not issued. The clinic is not Clinic B-2.

A draft column that mentions MH-6 can be mistaken for this packet's vehicle assignment. Not issued means the draft is not authority. Clinic B-12 is not the destination in NB-NOTE-17.
