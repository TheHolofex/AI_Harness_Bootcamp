# Accessibility and equivalent inspection

Every lot row is supplied as semantic text. No required fact depends only on a map, image, color, hover state, or scanned handwriting.

## Required access

- CSV headers `lot`, `permit`, `gate_window`, `route`, and `status` appear as text.
- `PENDING`, `AUTHORIZED`, `READY`, `OPEN`, and `NOT_AUTHORIZED` are readable text, not color alone.
- Extra navigation time does not change the hard gates.

If an equivalent path does not expose a lot, route, or status, record `HOLD`. The facilitator may help open the material, but the learner must inspect it themselves.
