# Accessibility and equivalent inspection

Every decisive note is supplied as semantic text. No required fact depends only on a map, image, color, hover state, or scanned handwriting.

## Required access

- Source files and the saved instruction must be keyboard reachable and screen-reader readable.
- IDs, times, and statuses appear as text rather than color alone.
- Screen output is plain text with `PASS` or `HOLD` on each line.
- Learners may enlarge text, change contrast, use voice control, or redirect command output without changing the task.
- Extra navigation time does not change the hard gates.

## Equivalent source path

An equivalent view must preserve:

1. the complete note text, including quoted hostile language;
2. issuer, date, crate, and document type;
3. the saved instruction as readable text;
4. screen results as text; and
5. the load receipt path as a file path another person can follow.

If an equivalent path does not expose a decisive note, the saved rule, or a screen result, record `HOLD`. The facilitator may help open the material, but the learner must be able to inspect it and make the judgment themselves.
