# What to keep doing

Whenever the machine changes — an operating-system update, a restart, an edit to your shell profile — open a terminal you started after the change and run the setup check in it. A tool counts as installed only when a process that started later still finds it; a PATH change that never reached your shell profile is the usual reason one does not.

**Write the request and the sharing limit before the AI runs.** Decide what you are asking for, and what may leave your machine, while you can still change your mind. Once the output exists, you are editing it instead of directing it.

Pick the claim in a draft that would cost you most if it were wrong — a number, a name, a date — open the source it came from, and read the two side by side. Do that before the draft goes anywhere, not after someone asks you where the figure came from.

**Save the exact first error before you change anything.** It names the failure; every message after it describes your repairs. Keep it in a file you can paste from, then change one thing and run the same check again.

Do not repeat the billed file-writing checks without a reason to doubt them. A saved result stands until the setup changes.
