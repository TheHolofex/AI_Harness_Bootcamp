# AI Harness Bootcamp 2

This directory holds the runnable course material built from the Reformation core. Modules are developed one at a time. The stable course skeleton remains one level up under `reformation/`.

## Available now

- [Module 0 · Setup and direct bounded work](module-00-setup/README.md)
- [Module 1 · Verify sources and outputs](module-01-mission-thread/README.md)

## Build rule

A module is not complete because its prose exists. It must have:

- learner-facing material;
- supplied cases and practice checks;
- platform or product adapters where needed;
- a frozen module Reference;
- executable structural and safety tests;
- independent technical, curriculum, adversarial, and voice reviews;
- explicit target-platform execution status; and
- a handoff into the next module.

Material for later modules is not drafted here until the current module closes its review gates.
