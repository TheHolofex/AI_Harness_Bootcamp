# Accessibility and equivalent inspection

Every run is supplied as semantic text. No required fact depends only on a map, image, color, hover state, or scanned handwriting.

## Required access

- Run files and the predicate spec must be keyboard reachable and screen-reader readable.
- Missing-input output includes the exact phrase `HOLD: missing input`.
- The sample size is sixteen. Extra navigation time does not change the hard gates.

## Equivalent source path

An equivalent view must preserve the complete run text, the first-failure notes, the reconciled counts, the frozen config, and the three predicate results. If it does not, record `HOLD`. The facilitator may help open the material, but the learner must inspect it themselves.
