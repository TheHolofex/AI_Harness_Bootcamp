# Module 5 protected-case custody contract

The deciding predicate is a protected copy the producer cannot edit. Learners may read `shared/controls/predicate.py`. That file is not the graded copy.

## Staff roles

- **Case custodian:** stores graded corpora and the protected predicate outside the learner repository.
- **Evaluator:** selects a corpus, records sample/notes/run order, and scores the public rubric.
- **Facilitator:** teaches the visible twelve-run set. The facilitator does not reveal graded first failures or predicate tokens.

## Required controls

1. Graded runs and decisive checks stay outside the student repository and producing model context.
2. The learner sees the public rubric and the supplied control.
3. Each case rotates which run is known-bad while preserving difficulty.
4. The producer cannot edit or select the deciding control.
5. Reassessment uses a new corpus and retains both attempts.

## Compromise rules

- A learner-visible answer key invalidates the case.
- A second learner-written checker cannot score the attempt.
- A sample chosen after outcomes invalidates that gate.
- A missing accessible equivalent holds the assessment.
