# Accessibility and equivalent inspection

Every decisive source is supplied as semantic text. No required fact depends only on a map, image, color, hover state, or scanned handwriting.

## Required access

- Source files and tables must be keyboard reachable and screen-reader readable.
- IDs, versions, times, and statuses appear as text rather than color alone.
- The source manifest provides stable filenames and hashes.
- The review surface must expose the same claim, source link, status, and decision in its accessible view.
- Learners may enlarge text, change contrast, use voice control, or redirect checker output without changing the task.
- Extra navigation time does not change the hard gates.

## Equivalent source path

An equivalent view must preserve:

1. the complete source text;
2. source ID, issuer, version, effective time, and scope;
3. table headers and row relationships;
4. supersession and status labels;
5. quoted hostile text without executing it; and
6. stable locators another person can follow.

If an equivalent path does not expose a decisive source or review-page state, record `HOLD`. The facilitator may help open the material, but the learner must be able to inspect it and make the judgment themselves.
