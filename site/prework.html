Traps worth knowing before you start

These cost the most time, and none of them announce themselves clearly.

You only ever type into PowerShell.

Windows ships three terminals that look alike, and commands are not interchangeable. Git Bash gets installed as a dependency, not as a second shell to learn.

A new terminal is required after every install.

A terminal reads PATH once when it opens. This is behind more “it didn’t install” reports than everything else combined.

The Codex app ignores OPENAI_API_KEY entirely.

Every other tool reads the variable; this one reads the key you paste into Sign in another way on its signed-out screen.

The permission mode is what switches the sandbox on.

Set it to Ask for approval beneath the message box, or Codex runs without the boundaries the rest of the week assumes.

The .LTS suffix on the Node package id is not optional.

Plain OpenJS.NodeJS installs a release too new for n8n.

Installing goose with winget gets you a different program.

An unrelated database tool shares the name. Install from aaif-goose instead.

OpenCode’s curl install command can’t run in PowerShell.

It is a bash script, and no PowerShell version exists. Use the cohort-pinned path.

OpenCode reads Claude Code’s files by default.

Set OPENCODE_DISABLE_CLAUDE_CODE=1 or your second engine quietly loads the first engine’s instructions.

Pi looks for its shell only when it first needs one.

A missing Git Bash fails mid-exercise rather than at setup.

n8n’s first screen looks like a signup and isn’t one.

It creates a local account on your own laptop. No subscription is involved.
