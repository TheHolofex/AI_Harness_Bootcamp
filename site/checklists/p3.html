Block teaching page

Operator pulse (required every block)

  1. Open chat Operator — Direction & Log. Paste the brief starter. Fill all five fields: Outcome, Done looks like, Bounds, Evidence standard, Stop/hand-back. Status must be LIVE before the mission.
  2. Use a separate build chat (not the operator chat). Follow the mission steps below against your LIVE brief.
  3. Back in Direction & Log, paste the log starter. Record: what you directed, mid-run changes, verdict (ACCEPT / REJECT / ACCEPT WITH FIXES), evidence pointers, what you still own.
  4. Against this block’s MVP list: mark met / not yet with evidence pointers. No inflation.
  5. Open a new chat Adversarial — P3. Paste frozen prompt + artifacts + provisional verdict. Copy final line into log: ADVERSARIAL: stood | wounded | failed — …. Fix if wounded.
  6. Fill ritual 0–3, mission HIT/PARTIAL/MISS, quality STRONG/ADEQUATE/WEAK, time to result (minutes). Deep mark if this block has one.
  7. Chat Operator — Transfer 30-60-90. Paste every-session prompt. Session-log row required even if the seed is small.

Mission steps (do these in order)

  1. engineering or mission_ops — do not switch.
  2. Path: instruments/p3_frozen_brief/BRIEF-v1.md.
  3. Folder: instruments/p3_frozen_brief/<track>/corpus/ including watchlist.csv.
  4. Save raw output. Do not change the brief between engines.
  5. Same brief, same corpus.
  6. Side-by-side fields. Count material disagreements (or document low-separation search).
  7. Show the assert + why discarded using non-model evidence.
  8. Final operational picture someone cold could read.
  9. Single-engine ban, kill rule, comparator habit.

Mastery floor (MVP) — evidence must survive adversarial

  1. Codex app and OpenCode unchanged brief.
  2. No model-invented join keys.
  3. Side-by-side, not vibes.
  4. Low-separation documented if fewer.
  5. Assert + discard reason.
  6. Supervisor-readable.
  7. Brief id BRIEF-v1.

Close the block

  1. Adversarial line present; measurement row written; transfer row written; you could defend this block to a peer.
