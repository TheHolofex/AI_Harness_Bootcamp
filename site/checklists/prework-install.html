Pre-work hub

Before you begin

  1. Finish before Monday Block 0. Plan ~2–4 hours. Seats/keys from staff may arrive mid-install — finish auth when they land.

  2. Copy prework/SETUP_LOG.md or any notes file. After each major step: result, error, fix, time. Bring it Monday.

  3. Home: Codex app · Second engine: OpenCode (usually Grok). Claude Code is optional only.

0. Baseline machine

  1. Win+R → winver. Update if you can. Log version.

  2. This PC → free space. Clean up if tight.

  3. Corporate lock? Escalate now. Log admin yes/no.

  4. You will sign into Codex and providers in a browser.

1. PowerShell readiness

  1. Start menu → PowerShell.

  2. Get-ExecutionPolicy -List
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Get-ExecutionPolicy -Scope CurrentUser

    If GPO blocks you, log the error and ticket support.

2. Git for Windows

  1. winget install --id Git.Git -e --source winget

    Or official Git for Windows .exe if winget is missing.

  2. Close and reopen so PATH updates.

  3. git --version
Test-Path "C:\Program Files\Git\bin\bash.exe"

    Record bash path for Pi.

3. Node LTS + Python

  1. winget install --id OpenJS.NodeJS.LTS -e --source winget
winget install --id Python.Python.3.12 -e --source winget

  2. Reopen PowerShell.

  3. node -v
npm -v
python --version
pip --version

    Fallback: py -3 --version.

4. OpenAI Codex app (primary home)

  1. Official Store/OpenAI Windows path for your course date. App launches from Start.

  2. If seats are not ready, install now and return to sign-in later.

  3. Documents\HarnessBootcamp\prework-smoke

  4. Prefer Windows-native agent. Log sandbox/approval mode.

  5. Agent creates the file in prework-smoke. Pass only if Explorer shows it.

5. OpenCode — required second engine (Grok)

  1. P3 runs the same frozen brief on Codex and OpenCode. OpenCode is the course second harness — typically with Grok (or a staff-pinned model).

  2. Use the cohort-pinned install link/one-liner from staff (commands change). Upstream starting point: opencode.ai and current Windows docs.

    Record in log: method · version (opencode --version or About).

  3. In OpenCode provider/model settings:

    1. Add Grok / xAI with the key or seat staff issued or the exact provider staff name for your cohort.
    2. Select that model as your class default.

    Do not commit API keys into git.

  4. Same folder as Codex smoke tests.

  5. Run a trivial task that creates from-opencode.txt. File must exist on disk.

  6. Paste a tiny paragraph and ask for a three-bullet summary. Confirms model path works before Monday.

6. Pi (bare loop)

  1. pi.dev/docs/latest/windows — Git Bash is the usual shell.

  2. Follow current official Windows install. Log method.

  3. C:\Program Files\Git\bin\bash.exe

  4. Trivial command or file create in prework-smoke.

7. goose

  1. Current goose Windows docs. Log desktop vs CLI.

  2. Keyring issues: env var / disable keyring per goose Windows notes.

  3. Prefer real goose write into smoke folder.

8. Obsidian + n8n

  1. Official installer. Any local vault proves launch.

  2. npm global or other cohort path. Example only if staff agree: npm install -g n8n.

  3. Open localhost URL it prints. Stop with Ctrl+C or app quit.

9. Course repo / operator pack

  1. git clone https://github.com/TheHolofex/AI_Harness_Bootcamp.git
cd AI_Harness_Bootcamp

  2. Brief, log, pass bars, adversarial, measurement, transfer templates.

  3. python3 -m http.server 8080

    Open http://localhost:8080/site/. Note twin-engine: Codex + OpenCode.
