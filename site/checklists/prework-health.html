How to run this gate

  1. This is the pre-work gate. Bring proof (this checklist progress + setup log + optional screenshots) to Block 0 verification.

    Mark a step only when it is truly done. FAIL without a written unblock means you are not ready.

  2. Folder:

    Documents\HarnessBootcamp\prework-smoke\

    Create it if needed. All four agent write proofs land here.

A. Baseline tooling

  1. Proof: winver note in your setup log.

  2. git --version

    Proof: version string in log.

  3. Test-Path "C:\Program Files\Git\bin\bash.exe"

    Or record your real bash path.

  4. node -v
npm -v
  5. python --version
pip --version

    Or py -3 --version.

  6. Get-ExecutionPolicy -Scope CurrentUser

    Expect RemoteSigned or less restrictive — or a documented GPO exception.

B. Four agents — real files on disk

  1. Expected name: from-codex.txt (or hello.txt renamed).

    Pass only if the file exists on disk in prework-smoke, not only if chat claimed success.

  2. Local Code session on prework-smoke. File visible in Explorer.

  3. Pi can run in the project dir; file exists on disk.

  4. After a successful goose session/recipe, file exists on disk in the smoke folder.

  5. In Explorer, confirm all four uniquely named files are present. If any are missing, re-run that agent before declaring GREEN.

C. Seats and modes

  1. Course seat active; you can open a project.

  2. You know whether you are in Ask vs higher access, and you are not clicking blind. Note mode in setup log.

  3. Code tab opens without 403/paywall block for your seat.

  4. Provider/credentials set per staff guidance; a session can start.

  5. App opens; a vault can be created or opened.

  6. You started n8n and loaded the editor URL successfully; you know how to stop it.

D. Operator pack awareness

  1. Standing files: Direction Brief, Operator Log, Pass bars, Adversarial, Measurement spine, Transfer 30-60-90.

    • Operator — Direction & Log
    • Adversarial — [block] (new each block)
    • Operator — Transfer 30-60-90

  3. Not “everything was fine.” Operators keep trails. If truly nothing failed, write the riskiest step and why it almost failed.

Gate result

  1. GREEN — all critical baseline + four-agent files + seats/modes (A+B+C) pass. Ready for Block 0 First Light.

    YELLOW — minor fail with staff-approved workaround documented in your log.

    RED — four-agent write proof incomplete or seats missing. Stay in pre-work/support. Do not expect Monday AM to install the world for the room.

  2. Setup log header complete. Optional: screenshot Explorer with four files + this checklist progress.

  3. Block 0 verifies this gate, then First Light. Bring charger. Sleep optional but recommended.
