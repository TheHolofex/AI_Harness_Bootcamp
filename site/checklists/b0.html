Operator pulse (required every block)

  1. Open thread Operator — Direction & Log. Paste the brief starter. Fill all five fields: Outcome, Done looks like, Bounds, Evidence standard, Stop/hand-back. Status must be LIVE before the mission.
  2. Use a separate build thread (not the operator thread). Follow the mission steps below against your LIVE brief.
  3. Back in Direction & Log, paste the log starter. Record: what you directed, mid-run changes, verdict (ACCEPT / REJECT / ACCEPT WITH FIXES), evidence pointers, what you still own.
  4. Against this block’s MVP list: mark met / not yet with evidence pointers. No inflation.
  5. Open a new thread Adversarial — B0. Paste frozen prompt + artifacts + provisional verdict. Copy final line into log: ADVERSARIAL: stood | wounded | failed — …. Fix if wounded.
  6. Fill ritual 0–3, mission HIT/PARTIAL/MISS, quality STRONG/ADEQUATE/WEAK, time to result (minutes). Deep mark if this block has one.
  7. Thread Operator — Transfer 30-60-90. Paste every-session prompt. Session-log row required even if the seed is small.

Mission steps (do these in order)

  1. Show health check GREEN or YELLOW with setup log. Four-agent smoke files exist (or re-run now). RED → rescue track.
  2. Open mission_flesh/b0/reports/. Confirm multiple report files. Note fields you’ll map (time, tag, summary).
  3. In build thread, direct Codex to build a local single-page viewer (HTML/JS OK) with timeline and filters over the reports. Offline preferred.
  4. Open the page (local server if needed). You can see multiple reports at once.
  5. Timeline sorts or filters events by time in an observable way.
  6. Change a filter; the list/map updates correctly.
  7. Prove a must-not case (wrong filter empty state, or excluded report stays out).
  8. Add/use reports/DELTA_new.md; show refresh/rebuild reflects it — or document the break and your redirect.
  9. In operator thread: goal → act → observe → correct → accept, using this mission — not generic slogans.

  2. Outcome is an instrument, not “explore the data.”
  3. Codex, Claude Code, Pi, goose each touch smoke folder.

  5. Must-not case checked.
  6. DELTA or documented failure path.

Close the block

  1. Adversarial line present; measurement row written; transfer row written; you could defend this block to a peer.
