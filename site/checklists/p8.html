Operator pulse (required every block)

  1. Open chat Operator — Direction & Log. Paste the brief starter. Fill all five fields: Outcome, Done looks like, Bounds, Evidence standard, Stop/hand-back. Status must be LIVE before the mission.
  2. Use a separate build chat (not the operator chat). Follow the mission steps below against your LIVE brief.
  3. Back in Direction & Log, paste the log starter. Record: what you directed, mid-run changes, verdict (ACCEPT / REJECT / ACCEPT WITH FIXES), evidence pointers, what you still own.
  4. Against this block’s MVP list: mark met / not yet with evidence pointers. No inflation.
  5. Open a new chat Adversarial — P8. Paste frozen prompt + artifacts + provisional verdict. Copy final line into log: ADVERSARIAL: stood | wounded | failed — …. Fix if wounded.
  6. Fill ritual 0–3, mission HIT/PARTIAL/MISS, quality STRONG/ADEQUATE/WEAK, time to result (minutes). Deep mark if this block has one.
