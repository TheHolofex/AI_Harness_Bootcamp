Block teaching page

Operator pulse (required every block)

  1. Open chat Operator — Direction & Log. Paste the brief starter. Fill all five fields: Outcome, Done looks like, Bounds, Evidence standard, Stop/hand-back. Status must be LIVE before the mission.
  2. Use a separate build chat (not the operator chat). Follow the mission steps below against your LIVE brief.
  3. Back in Direction & Log, paste the log starter. Record: what you directed, mid-run changes, verdict (ACCEPT / REJECT / ACCEPT WITH FIXES), evidence pointers, what you still own.
  4. Against this block’s MVP list: mark met / not yet with evidence pointers. No inflation.
  5. Open a new chat Adversarial — P4. Paste frozen prompt + artifacts + provisional verdict. Copy final line into log: ADVERSARIAL: stood | wounded | failed — …. Fix if wounded.
  6. Fill ritual 0–3, mission HIT/PARTIAL/MISS, quality STRONG/ADEQUATE/WEAK, time to result (minutes). Deep mark if this block has one.
  7. Chat Operator — Transfer 30-60-90. Paste every-session prompt. Session-log row required even if the seed is small.

Mission steps (do these in order)

  1. Path: mission_flesh/p4/vault_seed/.
  2. What the assistant may read/write; what must never leave the vault.
  3. Navigable structure (e.g. People / Systems / Events / Decisions). Not a dump of AI filenames.
  4. Clickable [[wiki-links]]; answer spans multiple notes.
  5. Second director-level question, same standard.
  6. Open each citation; mark support / partial / not supported.
  7. Because the trail failed audit — not because of vibes.
  8. Generated into the vault; citations you verified.
  9. What must live in a navigable system at work.

Mastery floor (MVP) — evidence must survive adversarial

  1. Access + never-leave rules.
  2. Navigable structure.
  3. Clickable links.
  4. Every cited note opened.
  5. Evidence-based.
  6. Links only.
  7. What vault cannot support.

Close the block

  1. Adversarial line present; measurement row written; transfer row written; you could defend this block to a peer.
How to use with the lead The lead operates this same list on screen. You check your own box when you finish the step — not when you watch it. If adversarial wounds an MVP item, uncheck it until fixed.
