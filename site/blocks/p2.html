Why this block exists

A stock assistant forgets how you work. A modded harness carries instructions, tests, memory, and skills across sessions. The dyno is a shared five-case test (D01–D05). You score baseline, change the walls, score again. Numbers beat “feels smarter.”

What you will leave with

  • Baseline D01–D05 · ≥2 wall changes · after-score · a red→green test story
  • Durability proof: a new chat still carries the craft
  • Transfer file open with Identity + P2 seed

Before you start

  • Confirm operator templates are present in your Codex app project (DIRECTION_BRIEF.md, OPERATOR_LOG.md)
  • Open instruments/p2_dyno — cases and the shared score sheet

Lead operate-along

The lead runs this same page on screen — brief co-written live, accepts and rejects narrated. You still run your own chair, and you check a box when you finish the step, not when you watch it.

Before lunch · Harness case talk (45 min) A real problem the lead solved with harnessed AI — 30 minutes of the case, 15 of discussion. Listen for problem → harness move → evidence; leave one Transfer seed.

Run of exercise

Work these in order and check each off as its proof exists. Progress saves in this browser — the same tick shows on the home page.

  1. In chat Operator — Direction & Log, work the five fields with the AI: Outcome, Done looks like, Bounds, Evidence standard, Stop/hand-back. Do not start the mission until status is LIVE — vague “explore the data” outcomes get challenged.
  2. Open instruments/p2_dyno — the cases folder and the shared score sheet.
  3. New chat, stock harness. Score each case PASS/FAIL with notes. This is the number your craft has to beat.
  4. Each wall is a real artifact in the app, not a habit you promise to keep — see the four walls below. Not one lucky prompt tweak.
  5. Show a red→green story where possible (fails stock / passes after).
  6. Cold new chat, rescore, compute the delta on the score sheet. Cold matters — a wall that only works while the old chat is open is not a wall.
  7. Restart or new chat still carries the craft; re-run one dyno item cold.
  8. One honest paragraph on the score sheet. Measurement deep mark: Dyno baseline n/5 → after n/5.
  9. Open the Transfer chat; fill identity and the harness/30-day seed while it is fresh.

The four walls you can move

Instructions → AGENTS.md at the project root, loaded every session — the difference between a rule you re-type and a rule the machine already has · Skills → a folder with a SKILL.md; the description line is what decides whether it fires unprompted, so write it as trigger conditions rather than a title · Memory → off by default; a recall layer, not where rules that must always hold belong — those go in AGENTS.md, the only one of the two you can commit · Tests → ≥2 machine-checkable cases, red→green if you can.

Operator pulse — required every block

The same six-beat ritual closes every half-day: it is how a mission becomes evidence. Paste-ready prompts →

  1. Build work stays out of the operator chat — the trail is the point.
  2. Back in Direction & Log: what you directed, mid-run changes, verdict (ACCEPT / REJECT / ACCEPT WITH FIXES), evidence pointers, what you still own.
  3. Against P2’s MVP list: met / not yet with evidence pointers. No inflation.
  4. Chat Adversarial — P2: frozen prompt + artifacts + provisional verdict. Copy the final line into your log: ADVERSARIAL: stood | wounded | failed. Fix if wounded.
  5. Ritual 0–3 · mission HIT/PARTIAL/MISS · quality STRONG/ADEQUATE/WEAK · time to result (minutes). Dyno deep mark for P2.
  6. Chat Operator — Transfer 30-60-90: paste the every-session prompt. A session-log row is required even if the seed is small today.
