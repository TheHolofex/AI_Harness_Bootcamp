Use the full 30 minutes

00–07 min Use MCP—or skip it

Start from the work boundary. Choose tools, resources, prompts, a direct API, or no integration based on the actual job.

07–14 min Choose and configure transport

Use local stdio for one host launching one process; use Streamable HTTP for a remote or multi-client service with real authorization.

14–22 min Inspect the contract

Read the command, provenance, descriptions, input and output schemas, annotations, server instructions, result bounds, and error behavior.

22–30 min Secure and operate

Set least privilege, approvals, timeouts, bounded retries, audit evidence, revocation, and a debugging order that starts with the visible failure.

Use the current protocol, not a memorized handshake

Current-version note · MCP 2026-07-28 The current protocol uses stateless, self-contained requests and no connection-scoped initialize handshake or protocol session. Compatible clients may still use an earlier negotiated revision. P3 is wire-version agnostic: inspect the effective surface, actual calls, and errors instead of assuming a memorized flow.

Apply the method to one real product

P3 does not ask you to recite MCP or build a toy server. It gives three search agents one reviewed connection, and makes what each may not reach a property of that surface rather than a request in a prompt.

Decide Why this connection has this shape

Confirm why P3 uses tools rather than resources or prompts, and local stdio rather than Streamable HTTP. It exposes no credential, network, or write surface.

Inspect See the effective contract

Verify the reviewed code and lockfile, startup command, root, server instructions, exact tools, schemas, annotations, allowlist, approvals, and timeouts.

Use Retrieve only decision evidence

List once, read each planned source once, reuse it across every claim it supports, and stop on an unexpected call or uncorrectable error.

Verify Shape is not truth

Use hashes and raw-source context to validate returned evidence, then disable the server and record whether the connection earned its overhead.
