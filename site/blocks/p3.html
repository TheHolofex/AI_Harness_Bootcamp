Why this block exists

Models are callable components. When they disagree, that disagreement is a sensor. Your job is adjudication with evidence outside either model’s confidence.

What you will leave with

  • Run BRIEF-v1 unchanged on Codex and Claude Code
  • Comparator table; ≥3 material disagreements or proof of search
  • Kill at least one model-asserted claim
  • Supervisor-readable adjudication note
  • Transfer P3 seed; full pulse

Before you start

  • Same track as P2
  • Both apps signed in
Every block ends with the operator pulse Direction Brief (LIVE) → Mission → Log + pass-bar draft → new Adversarial thread → Measurement spine row → Transfer pulse. See Pulse & threads for paste-ready prompts.

Run of exercise

  1. Open the chair

    Open your Codex project. Confirm operator templates are present (DIRECTION_BRIEF.md, OPERATOR_LOG.md, etc.).

    Open thread Operator — Direction & Log. Paste the Direction Brief starter from the operator pack.

  2. Co-write the Direction Brief until LIVE

    Work the five fields with the AI: Outcome, Done looks like, Bounds, Evidence standard, Stop/hand-back.

    Do not start the mission until status is LIVE. Vague “explore the data” outcomes get challenged — name the artifact.

  3. Run the mission

    Same track as P2. Open instruments/p3_frozen_brief/.

    1. Read BRIEF-v1.md — do not edit.
    2. Point both engines at your track corpus/.
    3. Run BRIEF-v1 on Codex → save output_codex.md.
    4. Run BRIEF-v1 on Claude Code → save output_claude.md.
    5. Fill COMPARATOR.md. Kill at least one bad claim. Write adjudication note.

    Joins use watchlist.csv IDs only — models do not invent join keys.

  4. Operator Log + pass-bar draft

    Back in Direction & Log, paste the log starter. Record verdict, evidence, what you still own.

    Self-check against PASS_BARS.md for P3 — met / not yet with pointers. No inflation.

  5. Adversarial review (new thread)

    Open a new thread titled Adversarial — P3. Paste the frozen prompt from the operator pack plus your artifacts and provisional verdict.

    Copy the final line into your log: ADVERSARIAL: stood | wounded | failed — …. Fix if wounded.

  6. Measurement spine

    Update MEASUREMENT_SPINE.md: ritual 0–3, mission HIT/PARTIAL/MISS, quality STRONG/ADEQUATE/WEAK, time to result (minutes).

  7. Transfer pulse

    Thread Operator — Transfer 30-60-90. Paste the every-session transfer prompt. Leave a session-log row even if the seed is small today.

Pass bar (mastery floor)

Full checklist: operator/PASS_BARS.md · section P3. MVP is not “it ran.” Evidence must survive adversarial review.

If you get stuck

  • Narrow data scope, not the judgment standard.
  • Re-read your LIVE brief — most chaos is an unbounded outcome.
  • Ask for a lead diagram of the one concept blocking you, then continue on your chair.
