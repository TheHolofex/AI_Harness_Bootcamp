Follow the spreadsheet through the graph

The workbook is both the intake and the product. n8n reads the six source columns, gives the text to one AI structure station, joins the answer back to the original row by id, applies a workstream rule, and writes all fourteen columns back to workboard.xlsx.

The graph also writes a CSV mirror and a run receipt for the verifier, the local PowerShell helper that checks exact row counts and policy values. Those two files are backstage evidence. The workbook stays the product you inspect.

Structured output is the handoff

The model returns id, workstream, priority, summary, and next_action for every source row. Those named fields let the graph route and apply policy without a person translating prose into spreadsheet cells.

If you get stuck

  • The workbook write says the file is busy, locked, or in use. Close every Excel window that has either workboard open, then execute the same n8n workflow again.
  • The generated workflow is missing. Run Prepare-P7.ps1 again in the PowerShell window that will start n8n. Import the exact JSON path it prints.
  • The extract node returns no rows. Confirm the sheet name is exactly AI Workboard, the input binary field is data, Header Row is on, and Include Empty Cells is on.
  • The xAI node returns 429 or quota wording. In Group into 5-Record Model Calls, change RECORDS_PER_MODEL_CALL = 5 to 10. In AI Structure Station, use batch size 2 and delay 1200 ms. Run the full workbook again.
  • The reopened workbook still has blank AI columns. Confirm the n8n write node finished, close the stale Excel window, and reopen mission_flesh\p7\workboard.xlsx.
  • Wave 2 still shows 60 rows. Close Excel, run Add-P7Wave2.ps1, inspect the 80-row blank workbook, close Excel again, and execute the same saved graph.
  • The verifier fails after a green n8n run. Read the first failed count or field. Compare it with the visible workbook before changing any node.
