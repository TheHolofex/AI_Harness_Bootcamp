Two controls, two rule styles

Codex app → two controls do different jobs: the sandbox decides which files and network the agent can reach; approvals decide when it pauses. Switching from Ask for approval to Approve for me changes who reviews the escalation — it does not widen the sandbox. · OpenCode → bounds are rules in opencode.json, not a mode you pick in a menu, and they resolve last-match-wins: a later allow overrides an earlier deny, so the shipped defaults read *.env deny, then *.env.example allow — the order is the whole meaning. Write one sentence on how the two tools express the same bound, and where enforcement is weaker or merely conventional.
