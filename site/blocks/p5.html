Start here

This morning you sealed a logistics second brain under OpenCode and Obsidian MCP. This afternoon the threat is the front door. Wednesday continues in OpenCode; Thursday returns to other harnesses.

Anyone who can put a file in front of your assistant can attack intake. The attack takes three forms:

  • A false citation that makes a real trail vouch for a lie
  • A field contradiction that puts two incompatible facts in one record
  • A hostile instruction that tries to direct your machine

Seven ordinary-looking logistics files mix all three. You know the classes are present. You do not know which files carry them. Checks do not need advance knowledge of the bad files.

One more pressure sits after triage. A file can look clean enough to accept and still be wrong for the brain. Unchanged is not the same as true. You will prove both.

Five operating ideas

Write these down first. Each idea decides a move you will make under pressure.

1. Three poisons hit three different things

A false citation corrupts your evidence. Open the source. Compare the lines. The required catch today is a real source that says something else.

A field contradiction corrupts your facts. Two incompatible assertions arrive as one record. Hold or reject. Never merge as-is.

A hostile instruction corrupts your control. Text shaped like an order to the assistant or a tool is data, not authority. Isolate. Then prove each named effect is absent.

2. Containment is an absence you can show

The chat cannot testify. Match each claim to its evidence class: vault baseline for vault paths; staging inventory for protected intake files; runtime config hash for the launcher; role-aware session audit for assistant and tool-call channels; tool inventory for Obsidian MCP absence. A vault baseline does not prove events outside the vault.

3. Catch poison with mechanical checks — then one approval

The exposed agent writes one candidate file only: out\triage_candidate.json. A deterministic script validates structure and evidence fields. You approve or reject once. On approval the script promotes triage_record.md. You do not hand-build the table. Summarization is not triage.

4. The machine flags. You decide.

Scale detection. Do not scale the verdict. An unsigned flag is not a catch. Permission modes and path limits never decide whether a claim is true.

5. Unchanged is not the same as true

This morning MCP was the only sanctioned write into the brain. This afternoon the exposed triage agent holds no MCP and no vault path. After the three catches, you still run a controlled acceptance of one clean-looking wrong file through the director write path, retrieve from the brain, see the wrong answer cited, and repair. Baseline PASS after repair means the store matches the freeze. Truth still needed the retrieval check.
