Why this block exists

A harness is the setup around a model that lets it act: tools, files, permissions, instructions, and your accept/reject loop. Today you will feel that loop before we name every part of it. You are not installing the stack from zero in class. You already did that in pre-work. Here we verify, then we direct.

What you will leave with

  • Show GREEN/YELLOW pre-work health check and setup log
  • Co-write a full LIVE Direction Brief (five fields)
  • Ship a working map from the synthetic report folder (timeline and filters)
  • Run a negative check and an update proof (or honest break + redirect)
  • Explain the harness loop from this run; complete log, adversarial, measure, transfer

Before you start

  • Pre-work GREEN or YELLOW
  • Codex project folder ready
  • Copy operator/ templates into the project
  • Open course site on a second window if you like
Every block ends with the operator pulse Direction Brief (LIVE) → Mission → Log + pass-bar draft → new Adversarial thread → Measurement spine row → Transfer pulse. See Pulse & threads for paste-ready prompts.

Run of exercise

  1. Open the chair

    Open your Codex project. Confirm operator templates are present (DIRECTION_BRIEF.md, OPERATOR_LOG.md, etc.).

    Open thread Operator — Direction & Log. Paste the Direction Brief starter from the operator pack.

  2. Co-write the Direction Brief until LIVE

    Work the five fields with the AI: Outcome, Done looks like, Bounds, Evidence standard, Stop/hand-back.

    Do not start the mission until status is LIVE. Vague “explore the data” outcomes get challenged — name the artifact.

  3. Run the mission

    Gate (first 15–20 min): Show pre-work health check. Four agent write-proof files should exist (or re-run quickly). RED students go to rescue track — do not block the cohort.

    Mission data: open mission_flesh/b0/reports/ (synthetic mission reports). Your outcome: a small local web map or timeline+filter view over those reports.

    In a build thread (not the operator thread), direct Codex to:

    1. Inventory the report folder and propose a minimal data shape.
    2. Build a single-page viewer (HTML/JS is fine) with timeline and filters.
    3. Load from the folder or a generated data.json.

    Accept checks you must run yourself:

    • Map/page opens and shows multiple reports.
    • Timeline control changes what you see or clearly sorts events.
    • At least one filter changes the visible set.
    • Negative check: filter or empty state that must not show a wrong report — verify.
    • Update proof: add reports/DELTA_new.md (provided) and show refresh/rebuild reflects it, or document the break and your redirect.

    Sample build prompt (edit to match your LIVE brief):

    Read mission_flesh/b0/reports/. Build a single-page local viewer (index.html + data.json if needed)
with timeline and filters over these synthetic reports. Keep it simple and offline.
When done, print how to open it and how to refresh after a new file is added.

  4. Operator Log + pass-bar draft

    Back in Direction & Log, paste the log starter. Record verdict, evidence, what you still own.

    Self-check against PASS_BARS.md for B0 — met / not yet with pointers. No inflation.

  5. Adversarial review (new thread)

    Open a new thread titled Adversarial — B0. Paste the frozen prompt from the operator pack plus your artifacts and provisional verdict.

    Copy the final line into your log: ADVERSARIAL: stood | wounded | failed — …. Fix if wounded.

  6. Measurement spine

    Update MEASUREMENT_SPINE.md: ritual 0–3, mission HIT/PARTIAL/MISS, quality STRONG/ADEQUATE/WEAK, time to result (minutes).

  7. Transfer pulse

    Thread Operator — Transfer 30-60-90. Paste the every-session transfer prompt. Leave a session-log row even if the seed is small today.

Pass bar (mastery floor)

Full checklist: operator/PASS_BARS.md · section B0. MVP is not “it ran.” Evidence must survive adversarial review.

If you get stuck

  • Narrow data scope, not the judgment standard.
  • Re-read your LIVE brief — most chaos is an unbounded outcome.
  • Ask for a lead diagram of the one concept blocking you, then continue on your chair.
