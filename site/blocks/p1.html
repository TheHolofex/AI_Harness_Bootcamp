Why this block exists

If you only prompt once, you get a frozen answer. Operators need a judgment product they can re-run: same format, fresh evidence, citations you can check. You will practice the difference between “the model wrote something nice” and “I own a regenerable brief.”

What you will leave with

  • LIVE brief with audience, format, citation rule, accept checks, stop conditions
  • Rerunnable path you can show (script, skill, or saved one-command flow)
  • Citation audit ≥5 claims with at least one forced correction
  • Delta test + stale-source test (visible failure on broken source)
  • Log draft-vs-judgment; full pulse

Before you start

  • B0 complete enough to use the Codex app comfortably
  • Open your Codex app project and confirm operator templates are present (DIRECTION_BRIEF.md, OPERATOR_LOG.md)

Lead operate-along

The lead runs this same page on screen — brief co-written live, the mission run in a build chat you can see, accepts and rejects narrated. You still run your own chair, and you check a box when you finish the step, not when you watch it.

Every block ends with the operator pulse Direction Brief (LIVE) → Mission → Log + pass-bar draft → new Adversarial chat → Measurement spine row → Transfer pulse. See Pulse & chats for paste-ready prompts.

Run of exercise

Work these in order and check each off as its proof exists. Progress saves in this browser — the same tick shows on the home page.

  1. Open chat Operator — Direction & Log. Paste the brief starter. Fill all five fields: Outcome, Done looks like, Bounds, Evidence standard, Stop/hand-back. Status must be LIVE before the mission — vague “explore the data” outcomes get challenged; name the artifact.
  2. Path: mission_flesh/p1/corpus/ — daily ops fragments with intentional citation targets. Note source files C1… and DELTA_patch.md.
  3. Direct Codex to produce daily brief + regenerate method (script or one clear command). Fixed sections (e.g. Shipped / Broken / Blocked / Asks — or ops Confirmed / Developing / Gaps). Every factual claim cites a file id as [C#] mapped to files. No invented sources.
  4. Run your regenerate path end-to-end without re-explaining the whole mission from memory — one command or documented step regenerates from the corpus folder.
  5. Personally check ≥5 claims against files. Record pass/fail. Force at least one correction.
  6. Add DELTA_patch.md (or equivalent). Regenerate. Note what changed and what correctly did not.
  7. Remove or rename one cited file. Regenerate. Failure must be visible — no silent omit, no invented cite.
  8. In the log: what is machine draft vs what you own as operator judgment.

Paste-ready mission prompt

Using only mission_flesh/p1/corpus/, build a regenerable daily status brief.
Output markdown + a small script or clear regenerate instruction.
Citation format [C#] mapping to filenames. Do not invent sources.

Operator pulse — required every block

The same six-beat ritual closes every half-day: it is how a mission becomes evidence. Paste-ready prompts →

  1. Build work stays out of the operator chat — the trail is the point.
  2. Back in Direction & Log: what you directed, mid-run changes, verdict (ACCEPT / REJECT / ACCEPT WITH FIXES), evidence pointers, what you still own.
  3. Against P1’s MVP list: met / not yet with evidence pointers. No inflation.
  4. Chat Adversarial — P1: frozen prompt + artifacts + provisional verdict. Copy the final line into your log: ADVERSARIAL: stood | wounded | failed. Fix if wounded.
  5. Ritual 0–3 · mission HIT/PARTIAL/MISS · quality STRONG/ADEQUATE/WEAK · time to result (minutes). Deep mark if this block has one.
  6. Chat Operator — Transfer 30-60-90: paste the every-session prompt. A session-log row is required even if the seed is small today.

Mastery floor — evidence must survive adversarial review

Mark met / not yet against your own artifacts. If the adversarial pass wounds an item, uncheck it until it is fixed.

  1. Audience, format, citation rule, accept checks, stop.
  2. Not a one-shot paste.
  3. Forced correction recorded.
  4. Change + stability noted.
  5. No silent omit / invented cite.
  6. Operator owns judgment.
  7. Adversarial line present; measurement row written; transfer row written; you could defend this block to a peer.

Pass bar (mastery floor)

MVP is not “it ran.” Evidence must survive adversarial review. Full checklist: operator/PASS_BARS.md · section P1.

If you get stuck

  • Narrow data scope, not the judgment standard.
  • Re-read your LIVE brief — most chaos is an unbounded outcome.
  • Ask for a lead diagram of the one concept blocking you, then continue on your chair.
