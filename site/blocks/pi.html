Ten implementations, one run-through

The lab files already contain each pattern in TypeScript. One setup block installs the pinned Pi packages and runs the offline checks. Each numbered block then prints its implementation, runs it against xAI, saves a JSON trace in runs, and ends with a named PASS line.

Keep one PowerShell window open and run the blocks in order. Do not edit the files between patterns.

What you will run

Prompt chain · routing · parallel fan-out/fan-in · orchestrator-workers · handoff · evaluator-optimizer · tool loop · planner-executor · reflection · supervisor with subagents as tools

Ready means The final console line says PI LAB VERIFY PASS patterns=10 and runs contains one result for every numbered pattern.

Run ten patterns

Copy each complete block into the same PowerShell window. Read the source that prints first, then follow the control-flow trace and result.

Setup · Prepare the Pi lab

Copy this block into PowerShell:

Set-Location "$env:USERPROFILE\Documents\HarnessBootcamp\AI_Harness_Bootcamp\mission_flesh\pi"
powershell -ExecutionPolicy Bypass -File .\scripts\Setup-PiLab.ps1

What you should see. The offline tests pass and the final line begins PI LAB READY patterns=10.

Pattern 01 · Prompt chain

Three agents pass one result forward: facts → decision → brief.

Copy and run:

Get-Content .\src\patterns\01-prompt-chain.ts

What you should see. A three-step trace, a compact brief, and PI PATTERN 01 PASS.

Pattern 01 is complete when the result reaches the brief writer through both earlier outputs.

If you get stuck

  • Setup stops. Keep the exact message, correct the named Node or environment-variable problem, and rerun Setup-PiLab.ps1.
  • A pattern stops. Rerun that same numbered block. Its result file is replaced, not duplicated.
  • The verifier reports a missing pattern. Run the named number, then rerun Verify-PiLab.ps1.
