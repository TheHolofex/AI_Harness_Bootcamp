Run of exercise

Work these in order and check each off as its proof exists. Progress saves in this browser — the same tick shows on the home page.

  1. Open chat Operator — Direction & Log. Paste the brief starter from the operator pack. Fill all five fields: Outcome, Done looks like, Bounds, Evidence standard, Stop/hand-back. Status must be LIVE before the mission — vague “explore the data” outcomes get challenged; name the artifact.

  3. What the assistant may read/write; what must never leave the vault.
  4. Navigable structure (People / Systems / Events / Decisions — or your own IA). Not a dump of AI filenames.
  5. Ask via Codex with vault access scoped in your brief. Clickable [[wiki-links]]; the answer spans multiple notes.
  6. Second director-level question, same standard.
  7. Open each citation; mark support / partial / not supported.
  8. Because the trail failed audit — not because of vibes.
  9. Generated into the vault; citations you verified.
  10. What must live in a navigable system at work.

A vault-scoped director prompt

Vault root: [path]. Only read/write inside this vault.
Organize the inbox into linked notes. Then answer:
1) What are the top operational risks this week and which notes support each?
2) What decision is blocked and what evidence is missing?
Cite notes as [[Note Name]]. Do not cite notes you did not create or that lack support.

Operator pulse — required every block

The same six-beat ritual closes every half-day: it is how a mission becomes evidence. Paste-ready prompts →

  1. Build work stays out of the operator chat — the trail is the point.
  2. Back in Direction & Log: what you directed, mid-run changes, verdict (ACCEPT / REJECT / ACCEPT WITH FIXES), evidence pointers, what you still own.
  3. Against P4’s MVP list: met / not yet with evidence pointers. No inflation.
  4. Chat Adversarial — P4: frozen prompt + artifacts + provisional verdict. Copy the final line into your log: ADVERSARIAL: stood | wounded | failed. Fix if wounded.
  5. Ritual 0–3 · mission HIT/PARTIAL/MISS · quality STRONG/ADEQUATE/WEAK · time to result (minutes). Deep mark if this block has one.
  6. Chat Operator — Transfer 30-60-90: paste the every-session prompt. A session-log row is required even if the seed is small today.
