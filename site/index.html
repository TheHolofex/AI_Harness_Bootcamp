What you learn

Nine project modules, one arc — first experience a complete guided build, then learn to direct, verify, bound, and transfer serious work.

B1 — Experience Build from supplied prompts

Copy two complete prompts to turn a provided report corpus into a beautiful, responsive operations dashboard.

P1 — Direct Build a daily status brief

Define and produce a regenerable brief with controlled sources, observable checks, and a clear release decision.

P2 — Tune Encode your craft

Improve harness config with measured deltas, author machine-checkable tests, install durable memory, and package skills that fire unprompted.

P3 — Verify Command many minds

Run the same brief on two engines, surface material differences, and resolve them against sources into one supervisor-ready recommendation.

P4 · P5 — Guard Work your knowledge, keep it clean

Scope AI into a linked vault, verify citations by walking the links, quarantine untrusted intake, and release only what clears the boundary.

P6 · P7 — Bound Bound autonomy

Write an autonomy contract on real tool levers, verify stop and restart, and choose an agent loop or fixed pipeline with a human gate on exceptions.

P8 — Transfer Transfer the method

Author endpoint policy first, measure hold/degrade when the model changes, and leave with a 30-60-90 plan you run at your own desk.
