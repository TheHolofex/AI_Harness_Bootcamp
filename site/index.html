What this school is

This is not a prompt class, a tool tour, or a deck series. It is an operator’s school. You direct outcomes, bounds, and standards of evidence. The model loops inside that frame. You accept or reject with proof.

The lead runs the same exercises live — talking through judgment, going deep with the AI to explain and diagram — while you keep your own chair and artifacts.

Open checklists

Before Monday

You install your own Windows workstation. There is no golden image. Verify at the end of each setup step as you go. Monday morning opens with an install clinic (~2 hours expected) to close gaps, then First Light.

Open pre-work module

Harness case talks

Tuesday, Wednesday, and Thursday mornings end with a 45-minute case talk before lunch: the lead walks a real problem they solved with harnessed AI (30 minutes), then the room discusses (15 minutes).

Thursday after lunch · Browser → deck demo

Before the automation-line block, the lead spends thirty minutes on the staff machine: the agent uses the built-in browser on scoped public pages, collates a short slideshow, and the room watches a claim get verified — then a stop. You do not install plugins or a Chrome extension. It extends Thursday morning’s contract language (deck ≠ truth), then hands off to pipelines.

Tracks

From Tuesday onward you pick one content track and keep it:

  • Engineering — CI, tickets, services, release truth
  • Mission / ops — sitreps, watches, field notes, briefs

Both are always available. Shared instruments (dyno, frozen brief, hold/degrade) exist for each.
