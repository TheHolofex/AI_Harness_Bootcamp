What you learn

Nine project modules, one arc — first experience a complete guided build, then learn to direct, verify, bound, and transfer serious work.

B1 — Experience Build from supplied prompts

Copy two complete prompts to turn a provided report corpus into a beautiful, responsive operations dashboard.

P1 — Direct Build a daily status brief

Define and produce a regenerable brief with controlled sources, observable checks, and a clear release decision.

P2 — Organize Build a local Project Organizer

Direct AI to turn messy project files into a source-linked SQLite ledger, four read-only local MCP tools, a focused skill and plugin, a bounded agent team, and a checked visual project board.

P3 — Verify Compare engines, verify evidence paths

Run one frozen brief on two engines, surface material differences, then use a bounded MCP source path and resolve every consequential claim against raw evidence.

P4 — Harness Build your personal operating loop

Encode a real goal, control pattern, durable state, human evidence gate, evaluator, verifier, and clean finish around a useful director's brief.

P5 — Guard Keep trusted knowledge clean

Start from P4's fingerprinted vault, quarantine untrusted intake, and prove hostile content had no effect on the trusted operating picture.

P6 · P7 — Bound Bound autonomy

Write an autonomy contract on real tool levers, verify stop and restart, and choose an agent loop or fixed pipeline with a human gate on exceptions.

P8 — Transfer Transfer the method

Author endpoint policy first, measure hold/degrade when the model changes, and leave with a 30-60-90 plan you run at your own desk.
