# Transfer cadence — facilitator card (Move 3)

## Current course flow

The living 30-60-90 is the **outer half of the circuit**. Its continuity lives in `TRANSFER_30_60_90.md`, not in a season-long chat.

The live HTML module pages are authoritative for learner steps and exact chat names:

- **B1** stays in `B1 — First Light Dashboard`; it does not open or seed the transfer plan.
- **P1–P6** write one dated seed during that module's own closeout.
- **P7** writes its dated seed, then opens `P7–P8 — 30/60/90 Plan` to draft the horizons.
- **P8** reopens or recreates that one shared plan chat to finalize and seal the same saved artifact only when the course model still matches. If the model changed, P8 starts the fresh continuation named on its live page. Chat history is not required.

## Chat split (enforce)

| Chat | When |
|---|---|
| `[MODULE] — Direction & Closeout` | When the module page uses a direction ritual; replace `[MODULE]` with the current code and follow the page's exact suffix |
| `[MODULE] — Adversarial Review — [DATE]` | Only when the module page directs a frozen review; new for that review |
| `P7–P8 — 30/60/90 Plan` | P7 horizon draft and P8 finalization only — the one intentional shared chat |
| Module build chats | During that module's mission only |

Do not create a global direction/log chat or a transfer chat that runs after every block. Module closeouts write the early seeds directly into the saved file.

## Module handoff

```text
Follow the live module page
    → save the module's dated seed in TRANSFER_30_60_90.md
    → at P7 only: draft horizons in P7–P8 — 30/60/90 Plan
    → at P8 only: finalize and seal in that same named planning role
```

| Module | Transfer action |
|---|---|
| B1 | None; complete the guided First Light dashboard flow |
| P1 | Judgment-product machine seed in the P1 closeout |
| P2 | Harness/30-day seed in the P2 closeout |
| P3 | Verdict/kill/comparator seed in the P3 closeout |
| P4 | Trail/knowledge target in the P4 closeout |
| P5 | Intake/trusted-picture seed in the P5 closeout |
| P6 | Contract/stop seed in the P6 closeout |
| P7 | Machine-choice seed, then draft 30/60/90 horizons in the shared plan chat |
| P8 | Finalize evidence, run the seal criteria, and seal or block |

An empty major seed on P2/P3/P5/P6/P7 day remains **not yet** until the module closeout names the missing value or its unblock.

## Time

| Pulse type | Box |
|---|---|
| P1–P6 dated seed inside module closeout | 2–5 min |
| P7 horizon draft | 12–18 min |
| P8 seal | 15–20 min |

**Rescue:** one real workload for 30 days — never dilute evidence language to “finish the form.”

## Friday rule

P8 seal is allowed only if the saved file shows dated P1–P7 seeds from the week.
A 30-60-90 created entirely on Friday morning is **not yet**, regardless of prose quality.
