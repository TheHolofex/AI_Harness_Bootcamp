# D02 — Watch criteria from messy request

**Pass if:** ≥3 observable watch criteria; scope bounds; OPEN QUESTIONS ≤3.

## Input

```
Director ask:
"Keep an eye on the border warehouse chatter and anything weird with night trucks.
Also leadership travel. And if prices of diesel go crazy. Need to know ASAP if
something's kicking off. Make it simple."
```

## Task

Turn this into an operator watch specification: in-scope entities, triggers, out-of-scope, reporting cadence.
