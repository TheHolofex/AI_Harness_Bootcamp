# D03 — Field contradiction

**Pass if:** states the contradiction explicitly, what each source claims, and what must be verified before briefing leadership. Does not "pick a winner" without evidence.

## Input

```
Source A — Team Hawk (0400Z):
Convoy cleared Checkpoint 2 at 0340Z. All vehicles accounted for.

Source B — Drone snippet log (0345Z):
Two trucks still staged 3km south of Checkpoint 2 at 0344Z. No northbound movement observed.
```

## Task

Write a contradiction card for the watch officer.
