# HarborLight maintenance pilot charter

The service organization is preparing a two-site maintenance pilot. The pilot
must make equipment alerts actionable for technicians without hiding the
operational risk of weak connectivity at the North Yard.

| field | value |
| --- | --- |
| project_id | PRJ-001 |
| name | HarborLight maintenance pilot |
| outcome | Launch a two-site maintenance pilot that routes validated equipment alerts to assigned technicians with a 15-minute triage target and a signed rollback plan. |
| success_measure | Both sites complete the go-live review; at least 90% of seeded alerts reach the assigned technician within 15 minutes; the rollback drill passes. |
| target_date | 2026-08-14 |
| sponsor | Elena Vasquez |
| project_lead | Priya Shah |
| current_phase | Build and readiness |
| source_id | SRC-001 |

The launch scope is North Yard and River Annex. Production automation outside
those sites is explicitly out of scope for this pilot.
