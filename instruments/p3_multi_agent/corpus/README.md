# Multi-agent review pack (frozen)

This folder is intentionally small. Three specialist subagents can each own one lens without needing a huge codebase.

| File | What it is |
|---|---|
| `service_snippet.py` | A small service-shaped Python module |
| `tests_snippet.py` | The tests that currently cover it |
| `NOTES_ops.md` | Operator notes from the desk that runs it |

Do **not** edit these files during the Many Minds stretch. Read-only review is the point.
